# Site Studio workspace

This repository is generated by Site Studio.

- `runtime/global/` contains global CSS, JavaScript, design tokens and runtime settings.
- `runtime/canvases/` contains visual page HTML, CSS, JavaScript and metadata.
- `runtime/blocks/` contains reusable code blocks.
- `runtime/templates/` contains theme templates.
- `runtime/snippets/` contains guarded PHP snippets.
- `plugin/igc-builder/` is a reviewable snapshot of the installed plugin source; Git import does not self-deploy it.

Edit runtime files, commit and push. In WordPress use Site Studio → Git Workspace → Pull & Import. PHP snippets are syntax-checked and scanned before any database changes are applied.
